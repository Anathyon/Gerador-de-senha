> Projeto moderno de geração de senhas com interface personalizável, responsiva e agora também disponível como **Progressive Web App (PWA)**.

[🔗 **Acessar Projeto no Vercel**](https://gerador-de-senha-swart.vercel.app)

---

## ⚙️ Funcionalidades

- 🔒 **Geração de senhas seguras**: combina letras, números e símbolos aleatórios.
- 🎚️ **Controle de tamanho**: ajuste o comprimento da senha com um controle deslizante.
- 📋 **Cópia com 1 clique**: clique no campo para copiar a senha gerada.
- 📱 **Interface responsiva**: funciona em qualquer tamanho de tela.
- ✨ **Feedback visual**: destaque interativo nos botões e campos.
- 🔋 **PWA (Progressive Web App)**: disponível para instalação como aplicativo no celular ou desktop, com suporte offline.

---

## 🛠️ Tecnologias Utilizadas

- **TypeScript** – Tipagem estática para maior robustez.
- **HTML5 + CSS3** – Estrutura e estilo modernos.
- **JavaScript/DOM** – Manipulação de elementos e eventos.
- **Service Worker + Manifest** – Habilitação da funcionalidade PWA.
- **Vercel** – Hospedagem gratuita com deploy automático.

## 🚀 Como Usar Localmente

```bash
git clone https://github.com/Anathyon/Gerador-de-senha.git
cd Gerador-de-senha
npm install
npm start
```

Depois disso, abra o navegador em `http://localhost:3000` ou conforme configurado.

---

## 📲 Instalação como App (PWA)

### ✅ Chrome / Edge (desktop)
1. Acesse [https://gerador-de-senha-swart.vercel.app](https://gerador-de-senha-swart.vercel.app)
2. Clique no botão “Instalar” que aparece na barra de endereços
3. Use como um app de verdade (modo tela cheia, sem URL)

### ✅ Android (Chrome / Firefox)
1. Acesse a mesma URL acima
2. Toque no menu (⋮) > **“Adicionar à tela inicial”**
3. O ícone do app será adicionado ao seu celular
